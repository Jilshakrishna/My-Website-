Jilsha Krishna — Personal Portfolio
A simple, responsive personal portfolio website for Jilsha Krishna, a Computer Science Engineering student.
Features
Introduction and About Me section
Education details
Skills list
Hobbies section
Projects section
Contact information
Welcome button with a JavaScript alert
Responsive layout for smaller screens
CSS included directly inside index.html (no separate style.css required)
How to Run
Download or clone this project.
Open index.html in any modern web browser.
No installation or build step is required.
Files
index.html — complete website HTML, embedded CSS, and small JavaScript interaction.
README.md — project overview and usage instructions.
Customization
Open index.html in a text editor to update the portfolio text, skills, projects, and contact details. The visual styling is inside the <style> section in the <head>.
The page loads the Poppins font from Google Fonts, so an internet connection is needed for that font. The site itself can still open offline using a browser fallback font.
